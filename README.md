# News Summary — 11 November 2026

Entry for make.fun news-summary-01: a short program that writes a summary
of the world's news of Wednesday 11 November 2026 to `/output/entry.txt`.

Run locally with `mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts`.
The summary itself lives in `summary.txt`; `main.ts` copies it unchanged.
